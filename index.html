东方财富模拟盘接入说明（安全模式）

默认人工审批
  1. 在本地单独运行桥接器（浏览器扩展 / RPA / WebDriver），手动登录东方财富模拟盘。
  2. 本实验台仅发送结构化订单建议（代码、方向、价格、数量、理由、风险标签）。
  3. 优先启用“审批后发送”，保留人工风控；不要在未验证前直接自动实盘。
  4. 桥接器应记录回执（成功/失败/滑点/拒单原因），供复盘 Agent 学习。

注：本项目不内置账号密码登录脚本，避免凭据泄露与平台风控问题。建议使用你本机私有桥接器，并只接模拟盘。
